# SoraChat

iPad・スマホ向けのチャットアプリです。LINE に近い見た目と操作で、トーク（1対1・グループ）、友だち、リアクション、返信、24時間ノート、プロフィールを備えます。

データベースは **Supabase（テキストだけ）** を使い、画像・ファイルは保存しません。プロフィール・グループのアイコン画像だけを Turso に保存します。Supabase Auth は使いません。

## 機能

- ログイン：仙人アカウントで続行（設定時）、またはユーザー名とパスワードで登録・ログイン
- 画面：下のタブで「トーク」「友だち」「その他」を切り替えます
- トーク：1対1とグループ（テキスト・連絡先、リアクション 👍 ❤️ 😂 😮 😢 🙏）
- 友だち：ユーザー名の検索かQRコードで追加します。友だちの削除もできます
- グループ：友だちの中から選んで作成・メンバー追加します。管理者が名前変更・メンバー削除、全員が退出
- ノート：60文字まで、24時間で消える一言
- 返信・メニュー：吹き出しをダブルタップするとメニューが開きます（返信・コピー・編集・送信・取り消し・転送）
- 通知：新着トークの Web Push（オン・オフ可）
- 投票：複数選択・匿名投票に対応。締め切りは作った人だけができます
- ミニゲーム（グループのトーク）：三目並べ・早押しクイズ・じゃんけん大会・数当て・連打バトル・反射神経バトル
- グループ通話（WebSocket で信号を中継）
- senninai（AIチャット）：設定の「AI」でオンにします（既定はオフ）
- オープンチャット、ブロック、友だち申請
- 管理者パネル：ユーザー・トーク・お知らせ・メンテナンス・IP BAN

## セットアップ

1. Supabase の SQL Editor で、次の5ファイルを **番号順** に実行します（何度実行しても安全です）。
   - `supabase/01_auth_users.sql`：ユーザー・セッション・登録・パスワード
   - `supabase/02_chat.sql`：会話・メッセージ・リアクション・投票・ミニゲーム
   - `supabase/03_social.sql`：友だち・友だち申請・ブロック・ノート
   - `supabase/04_notify_ai_realtime.sql`：通知・senninai の確認待ち・Realtime の公開設定
   - `supabase/05_migrate_remove_legacy.sql`：**既存のデータベースがある場合だけ**。削除した機能（ストア・Pay・拡張機能・作品など）のテーブル・列を取り除きます。**データを消すため、実行前にバックアップを取ってください。** 新しく作る場合は不要です。
2. Supabase の Realtime が有効になっていることを確認します（既定で有効）。
3. `.env.example` を `.env` にコピーして値を入れます。`SUPABASE_*`・`TURSO_*`・`MESSAGE_ENCRYPTION_KEY` は必須です。
4. `npm install` のあと、開発は `npm run dev`、本番は `npm run build` → `npm start` です。

## 検査

- `npm run typecheck`：型チェック
- `npm run test:senninai`：senninai のパーサーと流れ
- `npm run test:live`：ミニゲームの進行・連打の上限・反射神経の補正

## 注意

- 画像はアイコン（プロフィール・グループ）のみです。メッセージの画像・ファイル・スタンプは扱いません。
- 話しかけた内容は、senninai の応答のために外部のAIサービス（UserLocal）へ送られます。
- 仙人アカウントの連携（ポイント・ストア）は、この版には含みません。
